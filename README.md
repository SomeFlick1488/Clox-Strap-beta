CloxStraper

Space-style Roblox launcher: Launch (with friends list) · Accounts (password-locked) · Modifications · Presets · Roblox Editor · FFlag Editor · Scripts (optional) · Shortcuts · Settings. Languages: English, Українська, Русский. Default theme: Crimson. Default font: Comic Sans MS.

Build
Install Python 3.10+ (tick "Add to PATH").
Run build.bat.
Installer: dist\CloxStraper-Setup.exe -> installs to C:\Program Files\CloxStraper.

Data lives in %LOCALAPPDATA%\CloxStraper. Cookies are encrypted with Windows DPAPI; the Accounts password is stored only as a salted PBKDF2 hash. Passwords for Roblox logins are never saved.
